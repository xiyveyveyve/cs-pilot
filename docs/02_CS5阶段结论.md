## 三、★ CorrCom 层是运行时解密，静态不可读（事实，保留）

### 3.1 证据

把 `ICorrCom` 全族方法的**原始 IL 字节**打印出来，全部只有 4 字节：

```
BaseCorrCom.SendReturnBool      (3p)  00 00 17 2A
BaseCorrCom.SendReturnBoolThree (1p)  00 00 17 2A
BaseCorrCom.SendReturnPackage   (5p)  00 00 14 2A
CorrCom520.SendReturnBool*            00 00 17 2A     （全族相同）
CSTSerialPort.SendReturnBool*          00 00 17 2A
CSTSockect.SendReturnBool*             00 00 17 2A
CSTSockect.SendReturnPackage           00 00 14 2A
```

按 IL 指令表解码：

| 字节 | 指令 | 含义 |
|---|---|---|
| `00` | nop | 空操作 |
| `17` | ldc.i4.1 | 压入常数 1 |
| `14` | ldc.i4.0 | 压入常数 0（引用类型即 null） |
| `2A` | ret | 返回栈顶 |

→ **`SendReturnBool*` 恒返回 `true`，`SendReturnPackage` 恒返回 `null`。**

`SockectCom` 继承 `BaseCorrCom` 且自身 `SendReturnBoolThree` 无实现（IL=-1）。

### 3.2 推论（2026-11-11 修订）

**`CorrTest.CorrCom.dll` 被混淆器的运行时解密保护了**（ConfuserEx 式）。
这些 4 字节桩是静态视图下的占位，真实收发逻辑在运行时由解密器 patch 进去。

1. **对 CorrCom 层，静态 IL 反查完全失效**——此条成立（接管轮 11:32 独立复证）。
   在 `CorrData` / `CorrInterface` 层（无壳）IL 反查仍然有效。
2. ~~「两个失败点的成因可以对齐：GetOcpValueAutoRange NRE = SendReturnPackage 桩返回 null；
   SendMethodParams False = 运行时真实收发失败」~~ **已被接管轮修正**：
   - S3 NRE 真因 = 探针签名 bug + `ParsingParamsClass.context` 未注入（非桩返回 null）；
   - S4 False 真因 = 测试台 `--ack74 silent` 硬编码 + sim 分发 sub 索引错位 + `AA 52` 帧未实现
     （非「设备语义无解」）；ACK 判定本体 = **dataPacks 队列非空即过、内容无关**。

| [2] 族码 | 0x63 | 参数族标记（真机同 0x63） | 实测；含义未证实（09 号曾读作 LE 2403，存疑） |
| [3] sub | 0x0A（探针）/ 0x09（真机 09 号） | 参数块类型/序号/实验区分 | **未证实**（⚠ ACK 分发按 frame[3] 判 sub——接管轮修 bug 处） |
| [4..14] data | 探针轮**全零**；真机带实际参数、×9 帧分块 | 参数数据块（OcpParams 序列化分块？） | 探针轮 prm 全默认 → 全零，自洽；分块规则未证实 |
| [15] SUM | 0x9C | AA+85+63+0A=0x19C→0x9C ✓ | 验算 ✓ |

**行为观测**：探针轮 `0x85 63 0A` 单帧出现于 S2 参数注入段与 S4 前后（归属未证实——
SendMethodInit(ExpParamsBytes) 与 SendMethodParams 链的边界尚未逐帧对齐）；
echo 应答即可通过（ACK=队列非空）；真机 ×9 连发且带数据（09 号）。

### 10.3 S4 之外的配套帧（同轮实捕，供真机对照）

| 帧 | 实捕 | 应答（接管轮定案） | 说明 |
|---|---|---|---|
| `AA 80 53 …7D` | Stop 安全停 | echo | cmd=0x80 data[0]=0x53 |
| `AA CF 01 …7A` | 工作模式 | echo | 真机启动后回 `AA CF 01`（09 号） |
| `AA 53 01 …FE` | OCP 轮询 | **8B `AA 53+volt3B+curr2B+SUM`**（wati7；echo 不够） | ExpCallWatiFun 只认 len7(剥AA)，volt=(raw24−2^23)/2^23×10 |
| `AA 74 …1E` | 方法下载起始 | echo（16B） | GetMethodBytes 静态帧 |

> 结论：S4 帧1（0x74）静态、帧2（0x52）动态且其构造器本体在壳内——真机联调时按 §六-3
> 实录 0x85/0x52 的实机应答即可闭环。
